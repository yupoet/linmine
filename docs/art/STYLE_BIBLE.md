# 林脉 · 美术风格圣经（Happy Mall 系「小清新 Q 版」）

版本：2026-09-05 v1 · 状态：**定稿，作为所有美术改动的唯一依据**

参考对象：《开心商店 / Happy Mall Story》（Happy Labs）。公开评价："小清新风格、超 Q 人物设计、细腻画面，商店、场景、人物、连绿叶植物也透着萌"。

## 1. 一句话定义

**白天、暖色、奶油底、巧克力描边、圆润 Q 版、糖果饱和色、什么都在微笑。**

现状（深棕矿洞 + 火把琥珀 + 暗色 UI）与目标是反向的：这不是"加点可爱"，而是整体从**暗色矿洞**切到**明亮糖果乐园**。

### 2.3 方块专用底色（色盲审阅后的修订，grok 2026-09-05）

UI token 不变；以下三种方块的**实例底色**偏离 token，避免橙色族在红绿色盲下坍缩成一团：

| 方块 | 底色 | 说明 |
|---|---|---|
| 泥土 | `#8f5a2c`（木棕，比 `caramel` 深） | 与铜矿 `tangerine` 拉开明度 |
| 炸药箱 | `#b02232`（冷砖红，比 `cherry` 深） | 色盲下成为"深砖"而非第二种橙 |
| 宝库箱体 | `#d4891a`（琥珀） | 与金矿柠檬黄 `sun` 区分；溢出金币仍用 `sun` |

皮肤色无 token，统一用 `cream-100`；瞳孔/线条用 `cocoa-900`，永不用 `#000`。金矿 vs 宝库、补给 vs 出口靠**形状**区分（宝库=胖箱子、出口=全宽草带+彩旗），不能只靠填色。

规则：
- **任何颜色都是三段色**（本色 / 阴影 / 高光），场景用卡通分段着色，UI 用上亮下暗的两段渐变，二者的"亮/暗"用同一对 token。
- 全局**不出现纯黑 `#000`、纯白 `#fff` 大面积**；黑用 `cocoa-900`，白用 `cream-50`。
- 深度变暗：矿道越深，天空从 `sky` 过渡到 `lilac-dk` 的**傍晚薰衣草**，绝不到近黑；矿工头灯与方块自身高光保证 40 行以下依然可读。

## 3. 造型与线条

- **描边**：所有 3D 物体（方块、矿工、掉落物）与 2D 图标都有 **`cocoa-800` 粗描边**，线宽约为物体尺寸的 4–5%（1 单位方块 ≈ 0.045）。描边永远是"巧克力色"，不是黑。
- **体积**：立方体全部圆角化（roundedBox 半径 ≥ 0.14），顶面略亮、正面本色、侧面阴影——三面三段，来自 toon 分段而非真实光照。
- **卡通着色**：2–3 段色阶（`MeshToonMaterial` + 3 级 gradientMap），无镜面高光；金属类（金/铜）用**单点星形闪光**贴花（sprite）表现，而不是 PBR 反光。
- **Q 版比例**：矿工头：身 ≈ 1 : 0.9（头几乎和身体一样大），眼睛占脸高 35%，两颊 `blossom` 腮红，四肢短圆，无脖子；镐头夸张放大（头部宽度 ≈ 矿工头宽）。
- **拟人化**：方块不拟人，但**特殊方块带"表情"**——炸药箱有睁大的圆眼、补给箱是笑脸医药箱、宝库是抱着金币的胖箱子、出口层有闪星与"小旗子"。
- **绿植**：出口层与地面用 `mint` 圆球灌木 + 小花点缀，呼应"连绿植也萌"。

## 4. 场景（Three.js）

| 元素 | 现状 | 目标 |
|---|---|---|
| 天空/背景 | 浅蓝→近黑雾 | `sky-lt`→`sky` 渐变白天；深处过渡到 `lilac-dk` 傍晚；雾色同步，**永远有色** |
| 光照 | 半球 + 平行光 + 头灯，写实 | 单一暖平行光 + 强环境光；toon 分段决定明暗；头灯改为柔和 `sun-lt` 光晕 sprite |
| 泥土 | `#8a5a3b` | `caramel` 三段，顶面偶有 `mint` 草丛帽（表层行） |
| 岩石 | 灰 | `lilac` 三段 + 3–4 个圆点"石斑" |
| 铜 | 褐橙 | `tangerine` 底 + `sun-lt` 圆片矿脉 + 星闪 |
| 金 | 黄 | `sun` 底 + 白圆片 + 双星闪 |
| 基岩 | 深灰 | `slate` 三段 + 圆钉浮雕，边缘 `cocoa-800` 描边加粗 |
| 炸药箱 | 红方 | `cherry` 圆角箱 + 白圆眼 + 导火线小星 |
| 钻头箱 | 蓝方 | `sky` 箱 + 白色大箭头（方向明确）|
| 补给箱 | 绿方 | `mint` 箱 + 白十字 + 笑脸 |
| 宝库 | 黄方 | `sun` 胖宝箱，`caramel` 箱盖，金币溢出 |
| 出口层 | 单色带 | `mint` 草地带 + 白色栅栏 + 彩旗 + 星星，整行发亮 |
| 高亮可挖 | 描边框 | `sun-lt` 呼吸发光描边 + 顶部小"↓"箔片 |
| 粒子 | 碎屑 | 圆角胖碎块（继承本色三段）+ 星形闪光 + 金币飞出 |
| 弹出数字 | DOM | `sun` 字、`cocoa-800` 描边、圆体、上弹回落 |
| 矿工 | 写实比例 | Q 版：黄 `sun` 安全帽（`cherry` 帽带）、`sky` 工装、`cocoa-800` 描边、大眼、腮红、头身 1:0.9 |

性能约束不变：单 InstancedMesh（描边用第二个 BackSide InstancedMesh 共享 matrix），`MAX_*` 上限不变，像素比自适应不变，无纹理文件（所有"贴花"用 CanvasTexture 程序化生成一次性图集或 SDF 着色器）。

## 5. UI（DOM/CSS）

### 5.1 结构范式（照搬参考游戏的范式，重画每一个像素）

- **面板 Panel**：`cream-100` 底，外 `tan-300` 3px 边 + `cocoa-800` 1.5px 外描边，`radius 22px`，顶部 `cream-50` 高光带；标题栏为 `cream-200` 条 + 中央 `cocoa-800` 粗圆体标题。
- **主按钮 Button/primary**：`tangerine` 上亮下暗两段，底部 4px `tangerine-dk` "厚边"（3D 感），`cocoa-800` 2px 描边，`cream-50` 文字 + `cocoa-800` 文字描边；按下时下沉 3px、厚边消失。
- **次级按钮**：`sky` 同结构；确认/购买：`mint`；危险：`cherry`。
- **关闭按钮**：右上角 **`cherry` 圆角方块 + 白色粗 X**，略溢出面板边。
- **图标块 Icon tile**：56–64px 圆角方块，`cream-200` 底 + `tan-400` 斜面 + 深色图标。
- **资源胶囊 Pill**：`cocoa-900` 85% 透明胶囊，左侧 `sun` 金币圆形图标溢出，`cream-50` 数字。
- **标签页 Tabs**：文件夹式圆顶标签，选中为 `cream-100` 与面板连体，未选中 `tan-300`。
- **进度条**：`tan-300` 槛 + `cocoa-800` 描边，`mint` 圆头填充，左端 `sun` 星标。
- **提示/Toast**：白色 `cream-50` 圆角气泡 + 小尾巴，`cocoa-800` 文字；含 Q 版矿工头像的对话气泡用于教程。
- **缎带 Ribbon**：`cherry` 斜角"新"缎带用于新卡/新关卡角标。
- **卡牌 Card**：`cream-50` 卡面、`tan-300` 双边框、家族色顶带（generation=`mint`, income=`sun`, durability=`sky`, chain=`cherry`）、稀有度用 `blossom/lilac` 角星。
- **标题字**：白 `cream-50` 填充 + `cocoa-800` 3px 描边 + 下方 2px `cocoa-900` 投影，置于 `tangerine` 横幅上（标题屏"林脉"）。

### 5.2 字体

系统圆体栈优先（`ui-rounded, 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', 'Noto Sans CJK SC', system-ui`），权重 700–800；**不引入网络字体**（PWA 离线、CSP、体积）。用 `-webkit-text-stroke` + `paint-order: stroke fill` 做描边字。

### 5.3 动效

弹性 `cubic-bezier(0.34, 1.56, 0.64, 1)` 用于弹出/按钮；一切动效受 `.ui--calm` 关闭；无长于 400ms 的 UI 动效。

## 6. 各屏要点

- **标题屏**：白天天空 + 草地弧线 + 大号 Q 版矿工站姿 + `tangerine` 横幅 logo；单个 `mint` 大按钮"开始"。
- **选关**：每关一张 `cream-50` 卡，顶部小场景色块（关卡主题色）、`sun` 星星记录、锁定为 `tan-400` 灰化 + 挂锁。
- **卡牌 Draft**：三槽位 `tan-300` 凹槽，卡牌放入时弹跳。
- **HUD**：左上耐久 = `sun` 星标进度条；右上金币胶囊；顶部不遮挡矿道，全部半透明奶油。
- **结算**：`cream-100` 大面板，`tangerine` 标题横幅"到达/未到达"，金币逐条弹入，宝箱 Q 版跳动。
- **商店**：文件夹标签（镐 / 宝箱），商品卡 = 图标块 + `sun` 金币价签胶囊。
- **设置**：开关为 `mint`/`tan-400` 胶囊拨杆。

## 7. 验收标准（Definition of Done）

1. 任一屏截图放在参考截图旁，**外行能认出是同一画风**（调色、描边、圆角、按钮厚边）。
2. 场景无纯黑；40 行以下依然是有色傍晚。
3. 每个方块类型在 320px 宽屏上一眼可辨。
4. `npm run typecheck` / `npm test` / `node scripts/visual.mjs` 全绿；FPS 中位数不低于改动前的 90%（`?dev=1` 浮层读数）。
5. 依赖方向、`contracts.ts` 所有权、`RendererAPI` 签名、`onWave/onLand` 事件音频、槽位回收清理**零改动**。
6. 所有新文案经 `t()` 且有 zh 词条。
